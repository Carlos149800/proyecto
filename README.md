# Proyecto de Integración Continua

## Descripción

Este proyecto es una aplicación web sencilla desarrollada con HTML, CSS y JavaScript.

La aplicación permite al usuario agregar tareas a una lista.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git
- GitHub
